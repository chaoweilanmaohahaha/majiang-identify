# 增加上海敲麻胡牌识别

## Why

项目目标是识别不同种类麻将的胡牌情况。上海敲麻是第一个要支持的地方麻将变种。当前仓库只有 uni-app 脚手架，尚无任何麻将识别逻辑。本变更建立第一套胡牌/听牌判定能力，并奠定后续其他麻将变种可复用的输入表示与模块结构。

## What Changes

- 新增纯 TypeScript 麻将核心模块（不依赖小程序运行时），提供：
  - 牌的表示（27 种数牌 + 4 种风牌，花牌 11 种：春夏秋冬梅兰竹菊与红中/发财/白板）与手牌输入结构（手牌、副露、花牌、敲状态）。
  - 胡牌判定：给定 14 张牌（含副露），判断是否构成胡牌。
  - 胡牌类型识别：门清平胡、碰碰胡、清一色、混一色（可叠加）。
  - 听牌判定：给定 13 张牌（含副露），判断是否听牌及听哪些牌（听口），用于"听牌强制敲"规则。
- 新增单元测试（vitest），覆盖判定算法。
- 不包含小程序页面交互与番数/得分计算。

## Capabilities

### New Capabilities

- `shanghai-qiaoma-hu-recognition`: 上海敲麻的胡牌判定、胡牌类型识别与听牌判定。

### Modified Capabilities

（无，仓库目前没有既有 spec）

## Impact

- 新增源码目录（建议 `src/core/mahjong/` 或类似路径，纯 TS 逻辑，与小程序页面解耦）。
- 新增 devDependency：`vitest`（测试）。
- 不影响现有 `src/pages/**`、`src/App.vue` 等小程序页面代码。
- 无对外 API 或依赖变更。

## Non-goals（本次不做）

- 七对、字一色等更多胡牌类型。
- 番数/得分计算。
- 敲的时机校验（是否违规未敲等流程控制）。
- 小程序页面选牌/录入 UI。
